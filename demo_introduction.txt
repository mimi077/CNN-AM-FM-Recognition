Demo 介绍：基于 2D CNN 的 AM/FM 调制识别系统


【项目简介】

本 Demo 是一个交互式的无线电信号调制识别平台，通过 Web 界面直观展示 AM/FM 信号的调制、解调过程，并利用 2D CNN 模型实现调制方式的自动识别。


【核心功能】

1. 信号生成与处理
   - 生成原始信号，完成 AM（调幅）/ FM（调频）调制与解调
   - 支持调节载波频率、消息信号频率、信噪比（SNR）
   - 通过短时傅里叶变换（STFT）将 1D 时域信号转换为 2D 频谱图

2. AI 调制识别
   - 将 2D 频谱图输入训练好的 2D CNN 模型
   - 自动识别信号调制方式（AM / FM），输出预测结果与置信度


【技术路线】

代码生成信号 → 加高斯噪声 → STFT 转频谱图 → 2D CNN 分类 → AM/FM

- 训练数据：2000 个合成样本（AM/FM 各 1000，随机参数）
- 模型：4 层卷积神经网络，学习频谱图的时频纹理特征
- 部署：Flask 后端 + Cloudflare Tunnel 公网穿透，支持异地访问


【演示效果】

经实测，系统已部署至公网，支持异地访问，他人可通过链接直接体验完整的信号生成与 AI 识别功能。
